# Project Rules & Non-Negotiable Standards (HerRays — App of the Year 2027)

## Core Product Constraints
1. **Zero Guilt Mechanics:** Never use red warning badges, broken-streak penalties, or shaming copy. Missing a day must trigger a warm, effortless restart flow.
2. **< 2-Second Action Completion:** Completing a daily "Little Win" in the prototype must take one tap or gesture with immediate, tactile delight.
3. **No Generic Boilerplate:** All strategy/research documents in `docs/` must contain concrete frameworks, behavioral mechanisms, user segments, and evidence-graded interventions—never vague summaries or placeholder text (`[TBD]`, `Lorem ipsum`).
4. **Strict TypeScript:** All prototype code in `prototype/src/` must pass `npm run build` with zero warnings or errors.

## Workflow Rules
- Work on **ONE** task per session.
- Never mark a task `"completed"` in `tasks.json` until the Reviewer step approves it.
- Keep `PROGRESS.md` updated with concise, factual logs of what was built and verified.
